# UNICON TOOL — DOOR GAP TOLERANCE (CANON)

## PURPOSE
To verify door leaf gaps after frame installation.

The tool checks if door clearances are within
a strict, uniform tolerance.

This is a verification tool, not an adjustment guide.
## GAP TOLERANCE (LOCKED)

Uniform tolerance around door leaf:

TOP:    3 mm
SIDES:  3 mm
BOTTOM: 3 mm

No dynamic tolerance.
No profiles.
No per-door variation.

Pass / Fail only.
## MEASUREMENT POINTS

Gaps are measured at fixed locations:

- TOP LEFT
- TOP RIGHT
- SIDE LEFT (MID)
- SIDE RIGHT (MID)
- BOTTOM CENTER

Measurements are surface-to-surface.
## VISUAL FEEDBACK

GREEN:
Gap = 3 mm ± 0.5 mm
Acceptable

RED:
Gap < 2.5 mm or > 3.5 mm
Out of tolerance

No yellow state.
## DISPLAY RULES

- Only one gap shown at a time
- No continuous numbers
- Value appears only on hold or SNAP

Example:
"GAP: 2.4 mm — FAIL"
